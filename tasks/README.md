# Bảng việc mẫu | Sample task board

Mỗi mục dưới đây là một ý tưởng đóng góp thật, có thể tách thành issue và pull request riêng.

Each item is a real contribution idea that can become its own issue and pull request.

## Tài liệu | Documentation

- [ ] Bổ sung phần cài đặt bằng tiếng Việt và tiếng Anh.
- [ ] Thêm ví dụ quy trình issue, branch và pull request.
- [ ] Kiểm tra liên kết trong README.
- [ ] Thêm changelog cho bản phát hành đầu tiên.

## Chất lượng | Quality

- [ ] Thêm kiểm tra liên kết tự động.
- [ ] Viết checklist review pull request.
- [ ] Thêm mẫu issue báo lỗi.
- [ ] Thêm mẫu issue đề xuất tính năng.

## Cộng tác | Collaboration

- [ ] Đề xuất một cải tiến có bằng chứng sử dụng.
- [ ] Review một pull request của cộng tác viên.
- [ ] Cập nhật tài liệu theo một Discussion đã được xác nhận.

## Nguyên tắc | Principle

Không tạo thay đổi giả chỉ để tăng số liệu. Mỗi issue và pull request phải có mục đích, nội dung và bằng chứng kiểm tra.

Do not create fake activity to inflate metrics. Every issue and pull request must have a purpose, content, and verification evidence.
