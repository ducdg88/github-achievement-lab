# GitHub Achievement Lab

Một phòng lab công khai để luyện cộng tác GitHub bằng những đóng góp có ích thật.

A public lab for practicing GitHub collaboration through useful, real contributions.

## Mục tiêu | Goals

- Luyện quy trình issue, branch, pull request và review.
- Thực hành viết tài liệu song ngữ, test và changelog.
- Chào đón đóng góp nhỏ nhưng có thể kiểm tra được.
- Build a clean contribution history with issues, branches, pull requests, and reviews.
- Practice bilingual documentation, tests, and changelogs.
- Welcome small contributions that can be reviewed and verified.

## Bảng việc mở | Contribution board

Xem danh sách việc mẫu trong [`tasks/README.md`](tasks/README.md). Mỗi việc nên tạo thành một issue riêng trước khi sửa.

See the sample task list in [`tasks/README.md`](tasks/README.md). Create a separate issue before starting each task.

## Cách tham gia | How to contribute

1. Mở hoặc chọn một issue có mô tả rõ.
2. Tạo branch ngắn gọn từ `main`.
3. Gửi một pull request chỉ giải quyết một mục tiêu.
4. Chờ review, sửa theo góp ý và ghi rõ bằng chứng kiểm tra.

1. Open or choose a clearly described issue.
2. Create a short branch from `main`.
3. Submit one pull request for one focused goal.
4. Wait for review, address feedback, and include verification evidence.

Đọc [CONTRIBUTING.md](CONTRIBUTING.md) trước khi gửi thay đổi.
